## これは何？

[Claude Code](https://code.claude.com/docs/ja/overview) は Anthropic のAIコーディングエージェントです。このアプリは、その **応用的な拡張機能 — Skills（スキル）・Hooks（フック）・MCP・サブエージェント — と、それらを支える共通基盤（settings / CLAUDE.md / permissions）** を、レトロRPG風のクエストとクイズで学ぶ学習教材です。

インストールや起動方法などの初歩は扱いません。AIツールを使ったことがある人が「そこそこ使えるが、拡張機能は雰囲気で触っている」状態から一段深く理解することを狙っています。

- **チュートリアル**: 「Claude Code拡張の基本操作」14ステップ。設定ファイルの階層・Skill・Hook・MCP・サブエージェントの動きを模型画面で疑似体験
- **12のクエスト**: 設定の階層と permissions → CLAUDE.md → Skills → Hooks → MCP → サブエージェント → 組み合わせ運用、を段階的に学習
- **バトルクイズ68問**（クエスト内36問＋闘技場32問）: モンスターと戦いながら実務判断力をチェック
- **成長システム**: 経験値・レベル・称号・バッジ・モンスター図鑑（最終ボス: 混沌竜ツカイワケズ）

> ⚠️ 本アプリは個人が作成した**非公式のファンメイド学習教材**です。Anthropic 公式とは関係ありません。内容は 2026年7月時点の公式ドキュメント・公式ブログに基づいています。

## 操作方法

**十字キー（↑↓←→）＋ Enter だけで全操作できます**（マウスも使えます）。

- ↑↓: メニュー選択　- Enter: 決定／メッセージ送り　- ←→: クエスト本文のページめくり

## データについて

- 進捗（レベル・クリア状況）は**あなたのブラウザ内（localStorage）にのみ**保存されます。サーバーには何も送信されません
- 「はじめから」を選ぶと進捗が消えます
- ブラウザを変えると進捗は引き継がれません

## 動作環境

- PCブラウザ（Chrome / Edge 推奨）およびスマートフォン（画面下に十字キー＋Aボタンが表示されます）
- ドット字フォント（DotGothic16）はオンライン時のみ読み込まれます。オフラインでも動作はします
